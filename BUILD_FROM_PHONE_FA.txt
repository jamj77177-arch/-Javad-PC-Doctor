ساخت نسخه مستقل ویندوز با گوشی و GitHub
========================================

۱) در GitHub وارد حساب خود شوید و از علامت + گزینه New repository را بزنید.
۲) نام مخزن را Javad-PC-Doctor بگذارید. برای خصوصی ماندن کد، Private را انتخاب کنید.
۳) گزینه Add a README file را فعال نکنید و Create repository را بزنید.
۴) در صفحه مخزن، Add file و سپس Upload files را انتخاب کنید.
۵) فایل ZIP پروژه را در گوشی از حالت فشرده خارج کنید. محتویات پوشه Javad_PC_Doctor را انتخاب و بارگذاری کنید؛ خود پوشه مادر را دوباره داخل مخزن قرار ندهید.
   نکته: پوشه .github مخفی است. در فایل‌منیجر گوشی نمایش فایل‌های مخفی را فعال کنید و مطمئن شوید مسیر .github/workflows/build-windows.yml هم بارگذاری شده است.
۶) پایین صفحه Commit changes را بزنید.
۷) از تب Actions وارد گردش کار Build Javad PC Doctor for Windows شوید. اگر اجرای گردش کار خودکار شروع نشده، Run workflow را بزنید.
۸) پس از پایان موفق، به همان اجرای workflow بروید و از بخش Artifacts فایل Javad-PC-Doctor-Windows-Portable را دانلود کنید.
۹) ZIP دانلودشده را استخراج کنید. فایل JavadPCDoctor.exe و پوشه Reports آماده انتقال به فلش هستند.

نکات:
- برای ساخت EXE نیازی به نصب Python روی گوشی یا کامپیوتر مقصد نیست؛ ساخت روی Windows runner ابری GitHub انجام می‌شود.
- مخزن را Public نکنید مگر اینکه با عمومی شدن کد موافق باشید.
- تا وقتی در Actions عبارت موفقیت (سبز) و فایل Artifact را ندیده‌اید، EXE ساخته‌شده محسوب نمی‌شود.
