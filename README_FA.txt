Javad PC Doctor - نسخه 1.7.0
========================================

ساخت نسخه اجرایی ویندوز:
1) پوشه پروژه را روی Windows 10/11 کپی و استخراج کنید.
2) Python 3.10 یا جدیدتر را نصب کنید و گزینه Add Python to PATH را فعال کنید.
3) روی Build_Windows.bat دوبار کلیک کنید و تا پایان ساخت صبر کنید.
4) پوشه USB_Ready ساخته می‌شود؛ آن را روی فلش کپی کنید.
5) در کامپیوتر مقصد، JavadPCDoctor.exe را اجرا کنید. نصب لازم نیست.

آزمون واقعی ۳۰ دقیقه‌ای:
- دقیقه ۰ تا ۸: آزمون محاسباتی سبک CPU روی یک رشته پردازشی؛ عمداً از فشار چند‌هسته‌ای سنگین استفاده نمی‌شود.
- دقیقه ۸ تا ۱۴: تخصیص محدود RAM (حداکثر ۶۴ مگابایت) و نوشتن، بازخوانی و مقایسه الگوهای داده.
- دقیقه ۱۴ تا ۱۸: تلاش برای آزمون Direct3D بومی WinSAT؛ در صورت نبود ابزار یا پشتیبانی، GPU «قابل اجرا نیست» گزارش می‌شود و قبولی فرض نمی‌شود.
- دقیقه ۱۸ تا ۲۳: نوشتن، همگام‌سازی، بازخوانی و تطبیق SHA-256 یک فایل موقت ۱۶ مگابایتی روی درایو سیستم.
- دقیقه ۲۳ تا ۳۰: نمونه‌برداری واقعی دوره‌ای از بار CPU و مصرف RAM.

ایمنی و صداقت نتایج:
- پیش‌فرض آزمون سبک است و بار CPU به یک رشته و حدود ۱۵٪ چرخه زمانی محدود می‌شود.
- تست RAM محدود به حافظه‌ای است که خود برنامه تخصیص می‌دهد؛ این آزمون جایگزین MemTest86 بوتیبل برای بررسی کل RAM نیست.
- تست GPU فقط در صورت اجرای موفق WinSAT/Direct3D به‌عنوان اجراشده ثبت می‌شود. پایش حسگر به‌تنهایی تست عملکرد GPU محسوب نمی‌شود.
- تست دیسک از یک فایل موقت استفاده می‌کند و پس از پایان یا خطا برای حذف آن تلاش می‌شود؛ فایل‌های شخصی کاربر بازنویسی یا حذف نمی‌شوند.
- تست فایل موقت جایگزین SMART کامل، ابزار تشخیصی سازنده یا اسکن سطح کل دیسک نیست.
- دما فقط از سنسور واقعی و در صورت پشتیبانی نمایش داده می‌شود؛ مقدار ناموجود حدس زده نمی‌شود.
- «اجرا شد» به معنی عبور قطعی از معیار سلامت نیست. خطا، عدم پشتیبانی، توقف کاربر و داده ناموجود جداگانه گزارش می‌شوند.
- اگر آزمون لغو شود یا پیش از ۳۰ دقیقه پایان یابد، برنامه آن را آزمون کامل اعلام نمی‌کند.
- ارزیابی اولیه تکنسین (پایدار/ناپایدار) یادداشت داخلی است و هرگز نتایج اندازه‌گیری‌شده را تغییر نمی‌دهد.
- گزارش‌ها در پوشه Reports کنار فایل اجرایی ذخیره می‌شوند.

امکانات:
- داشبورد فارسی و رابط گرافیکی اختصاصی
- نمایش اطلاعات پایه سیستم، CPU، RAM، GPU و دیسک‌ها در حد دسترسی ویندوز
- پایش دما با منبع سنسور مشخص
- آزمون واقعی مرحله‌ای ۳۰ دقیقه‌ای با نوار پیشرفت، مرحله فعلی و زمان باقی‌مانده
- توقف دستی آزمون و ثبت نتایج ناقص بدون اعلام قبولی
- گزارش متنی شامل اندازه‌گیری‌ها، نتایج و محدودیت‌های هر آزمون
- ارزیابی اولیه تکنسین به‌صورت جدا از نتایج سخت‌افزاری
- اجرای قابل حمل از فلش
